## 一、项目背景

### 1.1 现状与动机

**创始人背景：**
- 重度普洱茶收藏者，专注 10 年以上中老期普洱茶，以大益品牌为主
- 运营过两个微信公众号：「渔夫的普洱日志」和「熟茶之美」，有一定行业知名度
- 因收益不明显 + 工作繁忙，接近一年未更新，与茶友接触减少

**核心痛点：**
- 公众号单向传播，缺乏茶友互动和社区感
- 无法沉淀茶品数据（品鉴记录、价格走势、存世量）
- 茶友之间的互换交流只能靠微信群，效率低
- 可信卖家缺乏展示渠道，买家缺乏信任依据

### 1.2 产品愿景

> 打造一个**以内容为核心、以信任为基础**的普洱茶爱好者社区平台。
> 让「写的人有动力、读的人有收获、买的人放心、换的人公平」。

### 1.3 目标用户

| 用户类型 | 画像 | 核心需求 |
|----------|------|----------|
| 普洱茶爱好者 | 喝了几年茶，想深入了解中老期茶 | 学习品鉴知识、看真实评测 |
| 收藏玩家 | 有一定存量，关注市场行情 | 茶品信息查询、行情参考 |
| 互换茶友 | 有藏品想流通，不一定为了赚钱 | 低成本找到想换的茶 |
| 认证卖家 | 专业茶商或资深藏家 | 开设频道展示和销售茶品 |
| 内容创作者 | 有品鉴能力，想分享 | 写作平台、粉丝积累 |

## 二、用户等级体系（平台核心机制）

> 等级体系是整个平台的信任基础设施，决定用户能做什么、不能做什么。

### 2.1 等级定义

| 等级 | 名称 | 达成条件 | 权限 |
|------|------|----------|------|
| Lv.0 | 茶客（游客） | 注册即得 | 浏览内容、评论（限2条/天） |
| Lv.1 | 茶友 | 注册满7天 + 发布1条品鉴笔记 | 发布品鉴笔记、评论不限、参与茶品讨论 |
| Lv.2 | 茶人 | Lv.1满30天 + 5篇品鉴 + 10条评论获赞 | 发起茶品互换、创建茶品百科条目 |
| Lv.3 | 茶师 | Lv.2满90天 + 15篇品鉴 + 累计50赞 + 无违规 | 申请认证卖家、开设频道 |
| Lv.4 | 茶宗 | Lv.3满180天 + 30篇品鉴 + 累计200赞 + 平台邀请 | 内容审核权、茶品鉴定意见优先展示 |
| 特殊 | 管理员 | 平台任命 | 全部权限 |

### 2.2 经验值来源

| 行为 | 经验值 | 说明 |
|------|--------|------|
| 每日登录 | +2 | 每日上限2 |
| 发布品鉴笔记 | +10 | 字数>200 |
| 发布深度文章 | +30 | 字数>1000，含图片 |
| 发表评论 | +3 | 字数>20 |
| 获得点赞 | +2/次 | 单篇上限20 |
| 茶品互换成功 | +15 | 双方确认收货后 |
| 成功交易 | +10 | 订单完成后 |
| 被举报违规 | -50 | 情节严重直接降级 |

### 2.3 升级自动化规则

```
用户每次操作后，系统自动：
1. 计算本次行为对应的经验值增量
2. 检查是否满足升级条件（经验值 + 时间 + 行为门槛）
3. 满足则自动升级，发放升级通知
4. 不满足则更新进度条，提示距离下一级还差什么
```

## 三、功能模块设计

### 3.1 模块一：博客与内容系统

#### 3.1.1 内容类型

| 类型 | 说明 | 谁可以发 | 权限要求 |
|------|------|----------|----------|
| **深度文章** | 长篇品鉴、产区知识、市场分析 | 创始人/特邀作者 | 管理员指定 |
| **品鉴笔记** | 单款茶的品鉴记录，结构化 | 所有 Lv.1+ | 茶友及以上 |
| **茶品百科** | 茶品基础信息（厂牌、批次、年份等） | Lv.2+ 可创建 | 茶人及以上 |
| **讨论帖** | 开放式话题讨论 | Lv.1+ | 茶友及以上 |

#### 3.1.2 品鉴笔记结构化模板

每篇品鉴笔记包含以下结构化字段：

```
茶品名称：[关联茶品百科]
冲泡方式：壶泡 / 盖碗 / 煮茶
投茶量：  Xg / XmL水
水温：    XX°C
外形：    ★★★★☆ (描述)
汤色：    ★★★★☆ (描述)
香气：    ★★★★☆ (描述)
口感：    ★★★★☆ (描述)
回甘：    ★★★★☆ (描述)
耐泡度：  X泡
综合评分：★★★★☆
总评：    [自由文本]
```

#### 3.1.3 内容互动

- 点赞 / 收藏 / 分享
- 评论（嵌套回复，最多3层）
- 关注作者
- 内容标签系统（按品牌、产区、年份、口感特征）

### 3.2 模块二：茶品互换交流

#### 3.2.1 互换流程

```
发布互换意向 → 匹配/浏览 → 私信协商 → 确认互换 → 各自发货 → 确认收货 → 互评
```

#### 3.2.2 互换帖结构

| 字段 | 说明 |
|------|------|
| 拥有（给出） | 茶品名称、数量、存储状态、照片 |
| 想要（换取） | 具体茶品 or 类型/价位范围 |
| 互换说明 | 自由描述补充 |
| 有效期 | 7天/30天/长期 |

#### 3.2.3 互换保障机制

- 双方确认后才进入发货阶段
- 平台记录物流信息（不上门收件，用户自理）
- 争议处理：双方各提交证据，Lv.4 茶宗投票裁决
- 互换成功率计入信用评分

### 3.3 模块三：认证卖家频道

#### 3.3.1 卖家认证流程

```
申请（Lv.3+） → 提交实名+茶品来源证明 → 平台审核 → 缴纳保证金 → 开通频道
```

#### 3.3.2 卖家频道功能

| 功能 | 说明 |
|------|------|
| 频道首页 | 卖家简介、主营茶品、信用评级 |
| 商品列表 | 茶品上架、价格、库存 |
| 促销活动 | 限时特价、组合优惠 |
| 内容营销 | 卖家可发布茶品介绍文章 |
| 评价系统 | 买家评价、评分 |

#### 3.3.3 交易保障

- 卖家保证金制度（保证金金额根据频道等级）
- 买家确认收货后才打款给卖家
- 7天无理由退换（茶品未拆封）
- 争议仲裁机制

### 3.4 模块四：云喝茶（实时茶席）

> "一个人喝茶是独享，一群人围观是仪式感"——云喝茶是平台最具差异化的社交功能。

#### 3.4.1 核心概念

用户开一席"茶"，相当于开一个实时聊天室。室主分享正在喝什么茶、冲泡过程、口感感受；围观茶友可以进入茶席实时互动、送茶礼、发表感想。

#### 3.4.2 茶席（TeaSession）生命周期

```
开席 → 分享中（实时互动） → 结席（自动生成品鉴记录）
```

| 阶段 | 室主操作 | 围观者可做 |
|------|----------|-----------|
| **开席** | 选择茶品 + 拍茶席照片 + 写开场白 | — |
| **分享中** | 发冲泡笔记、上传茶汤照片、语音留言 | 进入围观、实时聊天、送茶礼（虚拟）、提问 |
| **结席** | 写总结评语，一键生成品鉴笔记 | 查看回顾、继续评论 |

#### 3.4.3 茶席聊天室功能

| 功能 | 说明 |
|------|------|
| **实时消息** | 基于 WebSocket 的即时聊天，支持文字 + 图片 |
| **茶席信息卡** | 左侧/顶部固定展示：茶品名称、冲泡参数、已泡X泡 |
| **冲泡日志** | 室主每次注水/出汤可以更新状态，围观者实时看到进度 |
| **茶汤照片墙** | 室主上传每泡茶汤照片，自动按泡数排列 |
| **送茶礼** | 围观者可送虚拟茶礼（增加室主经验值），每日限额 |
| **弹幕模式** | 茶席人多时可切换为弹幕模式（类似B站） |
| **历史回顾** | 结席后可回看完整聊天记录和照片 |

#### 3.4.4 茶席大厅

- **正在进行的茶席**：实时列表，显示室主、茶品、围观人数
- **今日茶席推荐**：编辑精选的热门茶席
- **我关注的茶友开席通知**：关注的用户开席时推送通知
- **茶席日历**：预约茶席，提前预告（如"周五晚8点品03年大益7542"）

#### 3.4.5 茶席等级门槛

| 角色 | 门槛 | 说明 |
|------|------|------|
| 围观者 | Lv.0+ | 注册即可进入围观 |
| 发言者 | Lv.1+ | 茶友及以上可在茶席中发言 |
| 开席（室主） | Lv.2+ | 茶人及以上可以开自己的茶席 |
| 预约茶席 | Lv.2+ | 可以提前预约未来的茶席 |

#### 3.4.6 经验值关联

| 行为 | 经验值 | 说明 |
|------|--------|------|
| 开席 | +15 | 持续 > 30 分钟额外 +10 |
| 围观发言 | +2/次 | 每个茶席上限 10 |
| 收到茶礼 | +5/个 | 每个茶席上限 30 |
| 结席生成品鉴 | +10 | 室主结席时一键生成品鉴笔记 |

### 3.5 模块五：用户与社区

#### 3.5.1 用户主页

- 个人信息（茶龄、偏好、收藏方向）
- 等级徽章展示
- 发布的内容列表
- 品鉴统计（品鉴过多少款、偏好品牌、口感偏好图）
- 信用评分
- **茶席记录**：开过多少席、围观过多少席

#### 3.5.2 社区功能

- 关注/粉丝
- 私信系统（Lv.1+ 可发，防垃圾消息）
- 通知系统（评论、点赞、系统通知、**关注的人开席通知**）
- 话题标签（#大益 #中老期 #生茶 #熟茶）

user_actions (行为记录 - 经验值计算)

tea_sessions (云喝茶 - 茶席)

├── id, session_id → tea_sessions

tea_session_gallery (茶席茶汤照片墙)

## 七、设计风格

- **整体风格**：素雅、传统、有质感（中式茶文化气质）
- **配色**：以暖棕/茶色为主色调，米白背景，墨绿点缀
- **字体**：中文用思源宋体（标题）+ 系统默认（正文），英文用衬线体
- **图片**：大图展示茶品，高质量茶汤照片
- **移动端优先**：茶友多用微信和手机浏览

---

## 八、验证方案

### MVP 验证标准

1. **内容验证**：创始人能顺畅迁移 10+ 篇公众号文章，发布 20+ 条品鉴笔记
2. **用户验证**：邀请 20 位茶友内测，7 天内 10+ 人发布内容
3. **等级验证**：模拟用户从 Lv.0 到 Lv.2 的完整升级路径
4. **性能验证**：页面首屏 < 2s，API 响应 < 500ms
