# SKU 标准图谱库 Schema v1

> 用途:中老期鉴别"参照库"+垂直模型训练数据。原则:**溯源分级决定可信度权重**。

## 一、目录结构

```
sku-library/
├── _protocol/               # 采集与命名规范
│   ├── shooting-protocol.md # 拍摄标准
│   └── naming.md            # 文件命名规范
├── <sku_id>/                # 每个 SKU 一个目录
│   ├── meta.json            # SKU 元数据
│   ├── references/          # 正品参照样本
│   │   ├── ref-001/         # 一组参照(同一实物)
│   │   │   ├── front.jpg    # 版面正面
│   │   │   ├── back.jpg     # 版面背面(含内票)
│   │   │   ├── neifei-1.jpg # 内飞特写(微距,压入处)
│   │   │   ├── dapiao.jpg   # 大票/筒票

│   │   │   ├── cake-back.jpg   # 裸饼背面(饼窝)
│   │   │   └── cake-side.jpg   # 裸饼侧面(厚度/边缘)
│   │   └── ref-002/…
│   └── counterfeits/        # 已知仿品样本(同结构)
└── index.json               # 全库索引
```

## 三、溯源分级(可信度权重)

| Tier | 定义 | 权重用途 |
|------|------|---------|
| A | 自有实物+交易凭证 | 检索主库、训练正样本 |
| B | 拍卖行成交记录(仕宏/东和等,含图录) | 主库,次权重 |
| C | 权威图录/出版物扫描 | 对照库,注意版权仅自用 |
| D | 社区/茶友提交(经初筛) | 待验证池,复核后升级 |

## 四、拍摄标准(采集即护城河)

- 环境:自然散射光,避免直射与色温漂移;旁置灰卡/白卡便于后期白平衡校准
- 版面:展平拍摄+45° 抗反光角度各一张;微距拍中茶标、字体边缘、油墨网点
- 裸饼:正/背/侧三视角;内飞微距对焦在字口
- 分辨率:长边 ≥3000px;格式 RAW+JPG(RAW 留档,JPG 入库)

## 六、录入流程

1. 建 SKU 目录+meta(draft)
2. 按 tier 收图(references/counterfeits 分开)
3. 填 authentication_points(逐项:版面/内飞/饼形)
4. 专家复核 → status: reviewed → locked(锁定后改动须新版本)
